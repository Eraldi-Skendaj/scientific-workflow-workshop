# Contributing to the Workshop Repository

## Choose a contribution path

- If you have write access to this repository, create a branch here.
- If you use a standard GitHub account without write access, select **Use this template** and work in your own copy.
- If you use an Enterprise Managed User account, work in an organization-owned copy inside your enterprise. Managed users cannot fork or contribute to repositories outside their enterprise.

Do not add customer names, company names, event names, logos, internal URLs, or proprietary information.

## Browser-first workflow

1. Start from an issue or workshop instruction.
2. Create a uniquely named branch.
3. Make one focused change.
4. Use a commit message that describes intent.
5. Open a pull request and complete the template.
6. Request GitHub Copilot code review.
7. Evaluate every comment before applying a suggestion.
8. Request human review before merging.

For workshop exercises, leave the pull request unmerged unless the facilitator asks otherwise.

## Branch names

Use your GitHub username to avoid collisions:

```text
foundations/<username>-first-change
copilot/<username>-ae-summary
```

## Commit messages

Prefer:

```text
Document the review evidence for AE-3
Include life-threatening events in the AE summary
```

Avoid:

```text
update
fix
changes
```
