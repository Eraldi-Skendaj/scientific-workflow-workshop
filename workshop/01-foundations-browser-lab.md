# Foundations browser lab

## Goal

Use GitHub.com to make one focused documentation change and move it through a branch, commit, pull request, and review.

## Exercise

Work in pairs. Create one branch and pull request per pair.

Before editing:

- If your facilitator granted write access, work in this shared repository.
- Otherwise, use **Use this template** to create a personal copy.
- If you have a managed user account, use the enterprise-owned copy supplied by your facilitator.

1. Open `checks/expected-output.md`.
2. Select **Edit this file**.
3. Add this sentence beneath the expected record count:

   > Reviewers should confirm the count against the approved requirement before accepting a change.

4. Choose **Create a new branch for this commit and start a pull request**.
5. Name the branch:

   ```text
   foundations/<your-username>-review-note
   ```

6. Use this commit message:

   ```text
   Document the human count-verification step
   ```

7. Open the pull request and complete the template.
8. Exchange pull-request links with a partner who can access the same repository or copy.
9. Review your partner's diff and leave one evidence-based comment.

## Success criteria

- One focused change
- A branch with a unique name
- An intent-focused commit message
- A complete pull-request description
- One human review comment tied to the requirement or expected output

Do not merge unless the facilitator asks you to.
